Ask Matchi

An AI tutor that grades, quizzes and researches inside one chat that remembers the learner.

01

Why it exists

Students preparing for IELTS, a scholarship or an entrance test were juggling five tools: a chatbot, a quiz app, a grader, a search engine and a notebook. Ask Matchi puts all five in one conversation. It knows the learner’s goal, level and history, so every answer starts from where they are, not from zero.

Used byLearners on the MatchupSkills app (web and phone), in English, Indonesian or Dutch.
02

One request, step by step

Click a step, or press play, to follow one real request through the system.

Step 1 / 7 · Learner app

The learner asks

“Grade my IELTS Task 2 essay and give me a two-week plan.” The essay is attached as text.

trace
POST /chat{  "thread": "th_8f2…",  "text": "Grade my IELTS Task 2 essay and give me a two-week plan.",  "attachments": [{ "kind": "essay", "words": 287 }],  "lang": "en"}

Step 2 / 7 · Gateway

Gateway: who, and can they pay?

The session is verified and the plan and credit balance are checked before any paid model call. A learner without credits gets a clear message, never a half answer.

trace
const learner = await requireLearner(req);          // signed session onlyconst estimate = estimateTurnCost(body, learner.plan);if (!(await canSpend(learner, estimate)))  return reply(402, t('Top up to continue'));       // before any model call

Step 3 / 7 · Context

Context: who is this learner?

The prompt is built in layers. Fixed rules and the rubric come first and are cached, so they are not paid for again on every turn. Then a short profile card, a summary of earlier threads and the new message.

trace
system: [  { type: 'text', text: TUTOR_RULES + RUBRICS,          // ~6k tokens, same for all    cache_control: { type: 'ephemeral' } },  { type: 'text', text: profileCard(learner) },        // goal, level, exam date  { type: 'text', text: await memorySummary(learner) } // earlier threads, CV reviews]

Step 4 / 7 · Claude

The model plans

Claude reads the request and decides which tools it needs: grade the essay first, then check the official test dates on the web, then draw the plan. Tokens stream to the screen while it works.

trace
→ tool_use  grade_writing   { exam: "ielts", task: 2 }→ tool_use  web_search      { q: "IELTS test dates The Hague 2027" }→ tool_use  show_chart      { kind: "plan", weeks: 2 }

Step 5 / 7 · Tools

Tools do the real work

The grader scores the four IELTS criteria against band descriptors. Web results only reach the learner after the page is opened and checked: it must load, stay on the same site and actually contain the claim.

trace
{ "task_response": 6.5, "coherence": 6.0,  "lexical": 6.5, "grammar": 6.0, "overall": 6.5,  "fix_first": ["topic sentences", "linking beyond 'moreover'"] } sources: 2 found · 2 opened · 1 kept (1 redirected → dropped)

Step 6 / 7 · Database

Everything is recorded

The result lands in the learning activity index, so the dashboard, history and streak update without extra code. Every model call is logged with its cost, and research is billed at cost plus a fixed margin.

postgresql
insert into writing_results (learner, exam, overall, detail)values ($1, 'ielts', 6.5, $2);-- trigger → learning_activity (one row per session, any feature) insert into ai_cost_log (feature, model, input_tokens, cached_tokens, usd)values ('matchi', 'sonnet', 7412, 5980, 0.0213);

Step 7 / 7 · Stream

The answer arrives

The learner sees the band score, the two things to fix first, a two-week plan chart and source cards they can open. Total time to first word: about one second.

trace
stream: text · card(score) · chart(plan) · sources[1]first_token_ms: 980   total_ms: 11240   usd: 0.031

04

Code

Two pieces that carry the most weight in this agent.

A cited source must survive four checks before the learner sees it.

matchi/verify_link.jsjavascript
export async function verifyLink(url, claim) {  const u = new URL(url);  if (u.protocol !== 'https:' || isPrivateHost(u.hostname)) return drop('unsafe');   const res = await fetch(u, { redirect: 'manual', signal: timeout(6000) });  if (res.status >= 300 && res.status < 400) {    const to = new URL(res.headers.get('location'), u);    if (to.hostname !== u.hostname) return drop('redirects elsewhere');  }  if (!res.ok) return drop('dead link');   const text = readable(await res.text()).slice(0, _000);  if (!mentions(text, claim.keyTerms)) return drop('does not contain the claim');  return keep({ url: u.href, title: titleOf(text) });}

Research is charged at what it really cost, plus a fixed margin. Cached tokens are cheaper, so the learner pays less too.

matchi/billing.jsjavascript
export function creditsForTurn(usage, rates, margin = 0.5) {  const usd =      usage.input_fresh  * rates.input    + usage.input_cached * rates.cached      // ~10% of the fresh price    + usage.output       * rates.output    + usage.searches     * rates.search;  const charge = usd / (1 - margin);         // keep the margin on every turn  return Math.ceil(charge * CREDITS_PER_USD);}
05

Data and guardrails

What it keeps

  • threads · messagesthe conversation, per learnerkept while the account exists
  • learning_activityone row per session in any feature, filled by triggershistory and streaks
  • writing_results · quiz_resultsscores, criteria and feedbackkept for progress charts
  • saved_opportunitiesscholarships and jobs the agent founduntil the learner removes them
  • ai_cost_logmodel, tokens and cost of every callfinance and margin reports

What keeps it safe

  • Pay before you thinkCredits are checked before a paid call and refunded if the call fails.
  • No invented sourcesA link is shown only after it opened, stayed on its site and contained the claim.
  • One account, one memoryMemory, recall and translations are keyed to the account, so one learner can never shape another’s answers.
  • The model proposes, the server decidesEvery tool argument is validated on the server. The model cannot reach a table or a file directly.
