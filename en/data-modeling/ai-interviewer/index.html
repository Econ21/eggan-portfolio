AI interviewer

A seven-minute voice interview a candidate can take from any laptop, any time within 24 hours.

24 hvalid link, no login needed
~7 minper interview
~$0.17AI cost per interview
0hiring decisions made by the AI
01

Why it exists

Screening 80 applicants by phone takes a week of calls across time zones. The AI interviewer gives every candidate the same structured first conversation whenever it suits them. The team then watches the recording and reads the transcript before they decide.

Used byCandidates for roles at CAP and MatchupSkills; the hiring team reviews in the monitoring dashboard.
02

One request, step by step

Click a step, or press play, to follow one real request through the system.

Step 1 / 7 · Link gate

The link opens

The candidate opens a personal link. It works for 24 hours, needs no account and shows exactly what will be recorded. Nothing starts without consent.

trace
const row = await findByTokenHash(sha256(token));   // the token itself is never storedif (!row || row.expires_at < now()) return expired();if (!row.consent_at) return showConsent(row.position);

Step 2 / 7 · Candidate

Camera and microphone check

A short test confirms both devices work and the voice is loud enough, before the first question is asked.

trace
level = rms(micFrames) → 0.21  ✓ above 0.05video  = 1280×720 @ fps   ✓

Step 3 / 7 · Recorder

Answers are recorded in chunks

Video uploads in 10-second pieces straight to private storage. If the browser crashes, at most 10 seconds are lost and the candidate can reload and continue.

trace
recorder.ondataavailable = (e) =>  putChunk(sessionId, seq++, e.data);   // signed upload URL, private bucket// reload = new session; the last question is asked again

Step 4 / 7 · Speech→text

Speech becomes text

When the candidate stops talking, the answer is transcribed. The transcript, not the audio, is what the interviewer model reads.

trace
{ turn: 4, seconds: 52,  text: "In my last project I cleaned 30 thousand rows of survey data…" }

Step 5 / 7 · Interviewer

The interviewer asks the next question

Claude follows the role’s question plan and asks one follow-up based on what was just said. The role description and plan are cached, so each turn costs fractions of a cent. Hard brakes stop any runaway: a turn limit, a cost limit and a time limit.

trace
if (s.turns >= MAX_TURNS || s.usd >= MAX_USD || s.elapsed >= MAX_TIME)  return closeWith('Thank you, that is all for today.');const q = await interviewer.next({ plan, transcript: s.transcript });

Step 6 / 7 · Text→speech

The question is spoken

The question is read aloud in a natural voice. If the voice service fails, a second voice takes over; if both fail, the question appears as text and the interview goes on.

trace
audio = await speak(q, VOICE).catch(() => speak(q, BACKUP_VOICE)).catch(() => null);render({ text: q, audio });     // text always shown as captions

Step 7 / 7 · Review

The team reviews

At the end the chunks are joined into one video without re-encoding, a structured summary is written, and the team watches and reads. The AI never moves a candidate forward or rejects one.

trace
ffmpeg -f concat -i parts.txt -c copy interview.webm   # seekable, no quality losssummary: { strengths: 3, concerns: 2, quotes: 4 }  ·  status: unchanged

04

Code

Two pieces that carry the most weight in this agent.

A scheduled job makes sure nothing is left half-done, and that video is not kept longer than promised.

interview/sweep.jsjavascript
export async function sweep(db, store) {  // 1. abandoned: no answer for 15 minutes → close and summarise what exists  for (const s of await db.silentSessions({ minutes: 15 })) await finalize(s, { partial: true });   // 2. summaries that failed get up to three more tries  for (const s of await db.failedSummaries({ maxTries: 3 })) await summarise(s);   // 3. retention: video, transcript and scores go after 90 days unless hired  for (const s of await db.olderThan({ days: 90, exceptStatus: 'hired' })) {    await store.removeFolder(s.id);    await db.clearPersonalData(s.id);  }}

Three triggers may finish the same interview at once; only one wins the claim.

interview/claim.jsjavascript
const { data } = await db.from('interviews')  .update({ status: 'finalizing', claimed_at: new Date() })  .eq('id', id).eq('status', 'in_progress')        // compare-and-swap  .select('id').maybeSingle();if (!data) return;                                   // someone else is on it
05

Data and guardrails

What it keeps

  • interviewsposition, status, token hash, costs, timing90 days unless hired
  • recordingone seekable video file per interviewprivate storage, signed links
  • transcriptevery question and answer with timestamps90 days unless hired
  • scorecardsthe human interviewers’ scoreswith the application

What keeps it safe

  • Consent firstNothing is recorded before the candidate agrees to clear terms.
  • Hard brakesEach interview has a turn, cost and time ceiling, so a loop can never run up a bill.
  • Humans decideThe AI writes a summary. Only the team moves a candidate.
  • Delete on timeVideo and transcripts are deleted after 90 days, as the consent text promises.
