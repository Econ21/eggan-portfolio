05 · Northstar · in productie

Market desk

Een persoonlijke market desk die de markt leest, trade-setups voorstelt en zichzelf later beoordeelt. Hij plaatst nooit een trade.

3tijdframes samen gelezen: 1 u, 4 u, 1 dag
4analisten vergeleken: één op regels, drie AI
100%van de setups beoordeeld op echte koersen
0geplaatste trades
01

Waarom hij bestaat

Marktmeningen zijn goedkoop; bijgehouden meningen zijn zeldzaam. De desk schrijft elk idee op als precieze setup (waar instappen, waar het fout is, waar winst nemen) vóór de uitkomst bekend is, en controleert daarna de echte koersen. Zo leert hij welke soorten setups vertrouwen verdienen.

Gebruikt doorIkzelf. Het is een persoonlijke onderzoekstool in Northstar, mijn planningsapp.
02

Eén verzoek, stap voor stap

Klik op een stap, of druk op afspelen, om één echt verzoek door het systeem te volgen.

Stap 1 / 7 · Scheduler

Een nieuw pakket

Op een vast schema bouwt de desk een pakket: één momentopname van de markt die elke analist leest.

trace
packet { slot: "2026-11-21T08:00Z", assets: ["BTC","ETH","SOL", …],         macro: { dxy, us10y, fear_greed }, memory: {…} }

Stap 2 / 7 · Market data

Koersen ophalen

Candles voor drie tijdframes komen uit publieke marktdata, plus fundingrates voor crypto. Ontbrekende of verouderde data maakt het asset “niet gelezen” in plaats van te gokken.

candles("BTC", "1h", 500) · candles("BTC", "4h", 500) · candles("BTC", "1d", 400)if (ageMinutes(last) > 2 * tfMinutes) asset.read = null;   // no stale reads

Stap 3 / 7 · Indicators

Indicatoren berekenen

Per tijdframe: gemiddelden over 20 en 50 perioden, RSI, MACD, average true range (hoeveel de koers meestal beweegt) en de dichtstbijzijnde steun- en weerstandsniveaus.

Stap 4 / 7 · Rule engine

De regelmotor kiest een standpunt

De drie trendscores worden 50 / 30 / 20 (dag, 4 uur, uur) gewogen tot één getal. Dat geeft een standpunt, long, short of wachten, en een setup met instapzone, een stop op basis van volatiliteit en twee doelen. Geen AI in deze stap.

trace
composite = 0.5*0.6 + 0.3*0.4 + 0.2*(-0.2) = 0.38  → stance: longsetup { type: "trend_pullback", entry: 93.k–94.k, stop: 91.k,        tp1: 97.k, tp2: 101.k, rr: 1.6 }

Stap 5 / 7 · AI analysts

AI-analisten geven hun visie

Drie AI-analisten lezen hetzelfde pakket en schrijven eigen setups met redenen. Elke setup wordt gevalideerd: de stop aan de verlieskant, doelen aan de winstkant, en de beloning minstens 1,2 keer het risico. Ongeldige setups worden afgewezen, niet gerepareerd.

trace
cleanSetup(ai) → rejected: "stop above entry for a long"cleanSetup(ai) → ok { type: "breakout", rr: 2.1, confidence: 0.55 }

Stap 6 / 7 · Grader

Beoordelen met echte koersen

Later wordt elke setup afgespeeld tegen de candles die echt kwamen. Raakte de koers de instap? Wat kwam eerst: de stop of een doel? Het resultaat staat in R: winst of verlies uitgedrukt in eenheden van het genomen risico.

trace
grade(setup, candlesAfter) → { outcome: "tp1", r: +1.6, hours: 31 }grade(setup2, candlesAfter) → { outcome: "stopped", r: -1.0, hours: 9 }

Stap 7 / 7 · Journal

Geheugen voedt het volgende pakket

Winrate en gemiddelde R per setuptype en per analist gaan het volgende pakket in, zodat analisten zien welke ideeën echt werkten. Het journaal bewaart elke call met de uitkomst.

trace
memory.trend_pullback = { n: 46, win: 0.54, avgR: +0.31 }memory.mean_reversion = { n: 29, win: 0.38, avgR: -0.12, note: "skip against the daily trend" }

04

Code

Twee stukken die in deze agent het zwaarst wegen.

De regelmotor: weegt drie tijdframes tot één score en bouwt een setup met een stop op basis van volatiliteit.

markets/signal.jsjavascript
const WEIGHT = { '1d': 0.5, '4h': 0.3, '1h': 0.2 }; export function composite(tf) {  let s = 0, w = 0;  for (const [k, wt] of Object.entries(WEIGHT))    if (tf[k]?.trend_score != null) { s += tf[k].trend_score * wt; w += wt; }  return w ? s / w : 0;} function setup({ direction, entryLow, entryHigh, stop, targets }) {  const entry = (entryLow + entryHigh) / 2, risk = Math.abs(entry - stop);  if (!risk) return null;  const sign = direction === 'long' ? 1 : -1;  let [tp1, tp2] = targets;  if (tp1 == null || (tp1 - entry) * sign < 1.2 * risk) tp1 = entry + sign * 1.5 * risk;  if (tp2 == null || (tp2 - tp1) * sign <= 0) tp2 = entry + sign * 3 * risk;  return { direction, entryLow, entryHigh, stop, tp1, tp2,           rr: +(Math.abs(tp1 - entry) / risk).toFixed(2) };}

De beoordelaar loopt vooruit door echte candles. Raakt één candle zowel de stop als een doel, dan telt dat als verlies: de eerlijke aanname.

markets/grade.jsjavascript
export function grade(s, candles) {  const long = s.direction === 'long';  let entered = false;  for (const c of candles) {    if (c.time > s.expires_at) return { outcome: entered ? 'expired' : 'not_triggered', r: 0 };    if (!entered) { entered = c.low <= s.entryHigh && c.high >= s.entryLow; if (!entered) continue; }    const hitStop = long ? c.low <= s.stop : c.high >= s.stop;    const hitTp1  = long ? c.high >= s.tp1 : c.low <= s.tp1;    if (hitStop) return { outcome: 'stopped', r: -1 };          // stop first if both    if (hitTp1)  return { outcome: hitsTp2(s, c) ? 'tp2' : 'tp1', r: rOf(s, hitsTp2(s, c)) };  }  return { outcome: 'open', r: null };}

Data en vangrails

Wat hij bewaart

  • packetséén marktmomentopname per slotbewaard om opnieuw af te spelen
  • reportsde geschreven visie van elke analistbewaard
  • calls (setups)instap, stop, doelen, reden, bronalleen toevoegen, vóór de uitkomst
  • gradesuitkomst en R per callvoedt het geheugen

Wat hem veilig houdt

  • Alleen analyseEr is nergens in het systeem een beursaccount met handelsrechten.
  • Geen achterafEen call wordt opgeslagen vóór de uitkomst bekend is en kan nooit worden aangepast.
  • Alleen zinnige cijfersAI-setups met een stop aan de verkeerde kant of een slechte beloning worden afgewezen.
  • Verouderde data is geen dataZijn koersen te laat, dan wordt het asset overgeslagen in plaats van oude candles te lezen.
