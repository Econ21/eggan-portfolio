AI interviewer

Een spraakinterview van zeven minuten dat een kandidaat vanaf elke laptop kan doen, wanneer hij wil binnen 24 uur.

24 hgeldige link, zonder inloggen
~7 minper interview
~$0.17AI-kosten per interview
0wervingsbesluiten door de AI
01

Waarom hij bestaat

Tachtig sollicitanten telefonisch screenen kost een week bellen over tijdzones heen. De AI-interviewer geeft elke kandidaat hetzelfde gestructureerde eerste gesprek wanneer het hem uitkomt. Het team bekijkt daarna de opname en leest het transcript vóór het besluit.

Gebruikt doorKandidaten voor rollen bij CAP en MatchupSkills; het wervingsteam beoordeelt in het monitoringdashboard.
02

Eén verzoek, stap voor stap

Klik op een stap, of druk op afspelen, om één echt verzoek door het systeem te volgen.

Stap 1 / 7 · Link gate

De link opent

De kandidaat opent een persoonlijke link. Die werkt 24 uur, vraagt geen account en toont precies wat er wordt opgenomen. Niets start zonder toestemming.

trace
const row = await findByTokenHash(sha256(token));   // the token itself is never storedif (!row || row.expires_at < now()) return expired();if (!row.consent_at) return showConsent(row.position);

Stap 2 / 7 · Candidate

Camera- en microfooncheck

Een korte test bevestigt dat beide apparaten werken en de stem luid genoeg is, vóór de eerste vraag.

trace
level = rms(micFrames) → 0.21  ✓ above 0.05video  = 1280×720 @ fps   ✓

Stap 3 / 7 · Recorder

Antwoorden worden in stukken opgenomen

Video gaat in stukken van 10 seconden direct naar privé-opslag. Crasht de browser, dan gaat hooguit 10 seconden verloren en kan de kandidaat herladen en verder.

trace
recorder.ondataavailable = (e) =>  putChunk(sessionId, seq++, e.data);   // signed upload URL, private bucket// reload = new session; the last question is asked again

Stap 4 / 7 · Speech→text

Spraak wordt tekst

Als de kandidaat stopt met praten, wordt het antwoord uitgeschreven. Het transcript, niet de audio, gaat naar het interviewermodel.

trace
{ turn: 4, seconds: 52,  text: "In my last project I cleaned 30 thousand rows of survey data…" }

Stap 5 / 7 · Interviewer

De interviewer stelt de volgende vraag

Claude volgt het vragenplan van de rol en stelt één vervolgvraag op basis van wat net gezegd is. Rolbeschrijving en plan zijn gecachet, dus elke beurt kost een fractie van een cent. Harde remmen stoppen ontsporing: een beurt-, kosten- en tijdslimiet.

trace
if (s.turns >= MAX_TURNS || s.usd >= MAX_USD || s.elapsed >= MAX_TIME)  return closeWith('Thank you, that is all for today.');const q = await interviewer.next({ plan, transcript: s.transcript });

Stap 6 / 7 · Text→speech

De vraag wordt uitgesproken

De vraag wordt voorgelezen met een natuurlijke stem. Valt die dienst uit, dan neemt een tweede stem over; vallen beide uit, dan verschijnt de vraag als tekst en gaat het interview door.

trace
audio = await speak(q, VOICE).catch(() => speak(q, BACKUP_VOICE)).catch(() => null);render({ text: q, audio });     // text always shown as captions

Stap 7 / 7 · Review

Het team beoordeelt

Aan het eind worden de stukken zonder hercodering tot één video samengevoegd, wordt een gestructureerde samenvatting geschreven en kijkt en leest het team. De AI laat nooit een kandidaat door of wijst hem af.

trace
ffmpeg -f concat -i parts.txt -c copy interview.webm   # seekable, no quality losssummary: { strengths: 3, concerns: 2, quotes: 4 }  ·  status: unchanged
03

Tools die hij kan aanroepen

Het model kan alleen via deze tools handelen. Elke tool heeft een eigen regel, gecontroleerd op de server.

ToolWat hij doetToegangRegel
open_sessionControleert link, toestemming en resterende pogingenleestgehashte token, 24 u geldig
put_chunkSlaat een videostuk van 10 seconden opschrijftalleen privé-opslag
transcribeZet één antwoord om in tekstleestkosten per call gelogd

04

Code

Twee stukken die in deze agent het zwaarst wegen.

Een geplande job zorgt dat niets half blijft liggen en dat video niet langer bewaard wordt dan beloofd.

interview/sweep.jsjavascript
export async function sweep(db, store) {  // 1. abandoned: no answer for 15 minutes → close and summarise what exists  for (const s of await db.silentSessions({ minutes: 15 })) await finalize(s, { partial: true });   // 2. summaries that failed get up to three more tries  for (const s of await db.failedSummaries({ maxTries: 3 })) await summarise(s);   // 3. retention: video, transcript and scores go after 90 days unless hired  for (const s of await db.olderThan({ days: 90, exceptStatus: 'hired' })) {    await store.removeFolder(s.id);    await db.clearPersonalData(s.id);  }}

Drie triggers kunnen hetzelfde interview tegelijk afronden; maar één wint de claim.

interview/claim.jsjavascript
const { data } = await db.from('interviews')  .update({ status: 'finalizing', claimed_at: new Date() })  .eq('id', id).eq('status', 'in_progress')        // compare-and-swap  .select('id').maybeSingle();if (!data) return;                                   // someone else is on it
05

Data en vangrails

Wat hij bewaart

  • interviewspositie, status, tokenhash, kosten, timing90 dagen tenzij aangenomen
  • recordingéén doorzoekbaar videobestand per interviewprivé-opslag, ondertekende links
  • transcriptelke vraag en elk antwoord met tijdstempel90 dagen tenzij aangenomen
  • scorecardsde scores van de menselijke interviewersbij de sollicitatie

Wat hem veilig houdt

  • Eerst toestemmingEr wordt niets opgenomen vóór de kandidaat instemt met duidelijke voorwaarden.
  • Harde remmenElk interview heeft een plafond voor beurten, kosten en tijd, dus een lus kan nooit een rekening opdrijven.
  • Mensen beslissenDe AI schrijft een samenvatting. Alleen het team verplaatst een kandidaat.
  • Op tijd wissenVideo en transcripten worden na 90 dagen gewist, zoals de toestemmingstekst belooft.
