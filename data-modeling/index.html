Career Agent: levenscyclus van een sollicitatie

Eén verzoek, stap voor stap

Een leerling vraagt de Career Agent een cv op een vacature af te stemmen. De agent gebruikt twee Claude-modellen: een klein, snel model (Haiku) voor het gesprek en een sterker model (Sonnet) voor documenten. Probeert het kleine model het cv te schrijven, dan stopt de router die stap en herhaalt hem op het sterkere model. Chatten blijft goedkoop; documenten blijven goed.

Uurcandles worden features zonder look-ahead (elke input één bar verschoven). Een trendfilter plus RSI-pullback bepaalt de richting; de positiegrootte mikt op 40% jaarvolatiliteit; kosten bij elke positiewijziging.

northstar/market_desk/backtest.pypython
import numpy as np, pandas as pd YEAR = 24 * 365sharpe = lambda r: r.mean() / r.std() * np.sqrt(YEAR) # 1 · candles → features (no look-ahead: every feature is shifted)px = candles["close"]f = pd.DataFrame(index=px.index)f["ret"]   = np.log(px).diff()f["ema_f"] = px.ewm(span=12, adjust=False).mean()f["ema_s"] = px.ewm(span=48, adjust=False).mean()delta      = px.diff()gain, loss = delta.clip(lower=0), -delta.clip(upper=0)rs         = gain.ewm(alpha=1/14).mean() / loss.ewm(alpha=1/14).mean()f["rsi"]   = 100 - 100 / (1 + rs)f["vol"]   = f["ret"].rolling(24 * 7).std() * np.sqrt(YEAR) # 2 · signal: trend filter + RSI pull-back, sized to a 40% vol targetlong   = (f["ema_f"] > f["ema_s"]) & (f["rsi"] < 65)weight = (0.40 / f["vol"]).clip(upper=1.0).where(long, 0.0).shift(1) # 3 · backtest, 10 bp fee on every change in positionfee    = 0.001 * weight.diff().abs().fillna(0)strat  = weight * f["ret"] - feeequity = np.exp(strat.cumsum())dd     = equity / equity.cummax() - 1hold   = np.exp(f["ret"].cumsum()) report = pd.DataFrame({    "strategy": [equity.iloc[-1] - 1, sharpe(strat), dd.min()],    "buy_hold": [hold.iloc[-1] - 1, sharpe(f["ret"]), (hold / hold.cummax() - 1).min()],}, index=["return", "sharpe", "max_drawdown"]).round(3)print(report)print(f"trades={int((weight.diff().abs() > 0.05).sum())}  exposure={(weight > 0).mean():.0%}")
