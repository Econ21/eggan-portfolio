Ask Matchi

Een AI-tutor die beoordeelt, overhoort en onderzoekt in één chat die de leerling onthoudt.

12leertrajecten die hij aanstuurt
73%van de inputtokens komt uit de promptcache
3interfacetalen
0ongecontroleerde links getoond aan een leerling
01

Waarom hij bestaat

Studenten die zich voorbereiden op IELTS, een beurs of een toelatingstoets gebruikten vijf tools: een chatbot, een quiz-app, een beoordelaar, een zoekmachine en een notitieboek. Ask Matchi zet ze in één gesprek. Hij kent het doel, niveau en verleden van de leerling, dus elk antwoord begint waar de leerling staat.

Gebruikt doorLeerlingen in de MatchupSkills-app (web en telefoon), in het Engels, Indonesisch of Nederlands.
02

Eén verzoek, stap voor stap

Klik op een stap, of druk op afspelen, om één echt verzoek door het systeem te volgen.

Stap 1 / 7 · Learner app

De leerling vraagt

“Beoordeel mijn IELTS Task 2-essay en maak een plan voor twee weken.” Het essay zit erbij als tekst.

trace
POST /chat{  "thread": "th_8f2…",  "text": "Grade my IELTS Task 2 essay and give me a two-week plan.",  "attachments": [{ "kind": "essay", "words": 287 }],  "lang": "en"}

Stap 2 / 7 · Gateway

Gateway: wie, en kan hij betalen?

De sessie wordt gecontroleerd en het abonnement en tegoed worden nagekeken vóór elke betaalde modelcall. Zonder tegoed krijgt de leerling een duidelijke melding, nooit een half antwoord.

trace
const learner = await requireLearner(req);          // signed session onlyconst estimate = estimateTurnCost(body, learner.plan);if (!(await canSpend(learner, estimate)))  return reply(402, t('Top up to continue'));       // before any model call

Stap 3 / 7 · Context

Context: wie is deze leerling?

De prompt wordt in lagen gebouwd. Vaste regels en de rubric staan vooraan en worden gecachet, zodat ze niet elke beurt opnieuw betaald worden. Dan een korte profielkaart, een samenvatting van eerdere gesprekken en het nieuwe bericht.

trace
system: [  { type: 'text', text: TUTOR_RULES + RUBRICS,          // ~6k tokens, same for all    cache_control: { type: 'ephemeral' } },  { type: 'text', text: profileCard(learner) },        // goal, level, exam date  { type: 'text', text: await memorySummary(learner) } // earlier threads, CV reviews]

Stap 4 / 7 · Claude

Het model plant

Claude leest het verzoek en kiest de tools: eerst het essay beoordelen, dan de officiële testdata op het web checken, dan het plan tekenen. Tokens stromen al naar het scherm terwijl hij werkt.

trace
→ tool_use  grade_writing   { exam: "ielts", task: 2 }→ tool_use  web_search      { q: "IELTS test dates The Hague 2027" }→ tool_use  show_chart      { kind: "plan", weeks: 2 }

Stap 5 / 7 · Tools

Tools doen het echte werk

De beoordelaar scoort de vier IELTS-criteria op de banddescriptoren. Webresultaten bereiken de leerling pas nadat de pagina is geopend en gecontroleerd: hij moet laden, op dezelfde site blijven en de bewering echt bevatten.

trace
{ "task_response": 6.5, "coherence": 6.0,  "lexical": 6.5, "grammar": 6.0, "overall": 6.5,  "fix_first": ["topic sentences", "linking beyond 'moreover'"] } sources: 2 found · 2 opened · 1 kept (1 redirected → dropped)

Stap 6 / 7 · Database

Alles wordt vastgelegd

Het resultaat komt in de leeractiviteitsindex, zodat dashboard, geschiedenis en streak meeveranderen zonder extra code. Elke modelcall wordt met kosten gelogd en onderzoek wordt tegen kostprijs plus vaste marge gerekend.

postgresql
insert into writing_results (learner, exam, overall, detail)values ($1, 'ielts', 6.5, $2);-- trigger → learning_activity (one row per session, any feature) insert into ai_cost_log (feature, model, input_tokens, cached_tokens, usd)values ('matchi', 'sonnet', 7412, 5980, 0.0213);

Stap 7 / 7 · Stream

Het antwoord komt binnen

De leerling ziet de bandscore, de twee eerste verbeterpunten, een plan van twee weken en bronkaarten om te openen. Tijd tot het eerste woord: ongeveer een seconde.

stream: text · card(score) · chart(plan) · sources[1]first_token_ms: 980   total_ms: 11240   usd: 0.031

04

Code

Twee stukken die in deze agent het zwaarst wegen.

Een geciteerde bron moet vier controles doorstaan voordat de leerling hem ziet.

matchi/verify_link.jsjavascript
export async function verifyLink(url, claim) {  const u = new URL(url);  if (u.protocol !== 'https:' || isPrivateHost(u.hostname)) return drop('unsafe');   const res = await fetch(u, { redirect: 'manual', signal: timeout(6000) });  if (res.status >= 300 && res.status < 400) {    const to = new URL(res.headers.get('location'), u);    if (to.hostname !== u.hostname) return drop('redirects elsewhere');  }  if (!res.ok) return drop('dead link');   const text = readable(await res.text()).slice(0, _000);  if (!mentions(text, claim.keyTerms)) return drop('does not contain the claim');  return keep({ url: u.href, title: titleOf(text) });}

Onderzoek wordt gerekend tegen wat het echt kostte, plus een vaste marge. Gecachte tokens zijn goedkoper, dus de leerling betaalt ook minder.

matchi/billing.jsjavascript
export function creditsForTurn(usage, rates, margin = 0.5) {  const usd =      usage.input_fresh  * rates.input    + usage.input_cached * rates.cached      // ~10% of the fresh price    + usage.output       * rates.output    + usage.searches     * rates.search;  const charge = usd / (1 - margin);         // keep the margin on every turn  return Math.ceil(charge * CREDITS_PER_USD);}
05

Data en vangrails

Wat hij bewaart

  • threads · messageshet gesprek, per leerlingbewaard zolang het account bestaat
  • learning_activityéén rij per sessie in elke functie, gevuld door triggersgeschiedenis en streaks
  • writing_results · quiz_resultsscores, criteria en feedbackbewaard voor voortgangsgrafieken
  • saved_opportunitiesbeurzen en vacatures die de agent vondtot de leerling ze verwijdert
  • ai_cost_logmodel, tokens en kosten van elke callfinanciële en margerapporten

Wat hem veilig houdt

  • Eerst betalen, dan denkenTegoed wordt gecontroleerd vóór een betaalde call en teruggestort als die faalt.
  • Geen verzonnen bronnenEen link verschijnt pas als hij opende, op zijn site bleef en de bewering bevat.
  • Eén account, één geheugenGeheugen, recall en vertalingen hangen aan het account, dus de ene leerling kan de antwoorden van een ander nooit beïnvloeden.
  • Het model stelt voor, de server beslistElk toolargument wordt op de server gevalideerd. Het model kan nooit direct bij een tabel of bestand.
