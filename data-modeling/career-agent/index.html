Career Agent

Zoekt vacatures, schrijft de documenten en volgt elke sollicitatie tot het aanbod.

10fases per sollicitatie
2modellen: klein voor chat, sterk voor documenten
$0.12voor een volledig afgestemd cv-verzoek
0feiten die de agent mag verzinnen
01

Waarom hij bestaat

Werkzoekenden sturen tientallen sollicitaties, raken het overzicht kwijt en sturen overal hetzelfde cv. De Career Agent houdt één bewijsbank bij van wat iemand echt deed, stemt elk cv en elke brief daarop af en houdt een eerlijke tracker bij van “bewaard” tot “aangenomen”.

Gebruikt doorWerkzoekenden op MatchupSkills, van studenten die stage zoeken tot professionals die van vak wisselen.
02

Eén verzoek, stap voor stap

Klik op een stap, of druk op afspelen, om één echt verzoek door het systeem te volgen.

Stap 1 / 7 · Job seeker

Er komt een vacature binnen

De werkzoekende plakt een vacature voor data-analist en vraagt een afgestemd cv.

trace
"Here's a Data Analyst ad (Rotterdam, hybrid). Tailor my CV and save it."

Stap 2 / 7 · State

De status laden

De agent leest profiel, bewijsbank en tracker, zodat hij weet wat al verstuurd is en wat de persoon kan bewijzen.

trace
career_get_state() → { profile, evidence: 41 items, applications: 37,  duplicates: ["same company, other role (applied 9 days ago)"] }

Stap 3 / 7 · Tools

Vacature bewaren en scoren

De vacature wordt bewaard en gescoord tegen het bewijs: gevraagde vaardigheden gevonden, ontbrekend en riskant. Hier is de match 70/100 en de agent zegt welk gat telt.

trace
save_jobs([{ title: "Data Analyst", city: "Rotterdam" }])score_fit → { score: 70, band: "risky",  matched: ["SQL", "Power BI", "stakeholders"],  missing: ["dbt"], note: "say SQL pipelines, not dbt" }

Stap 4 / 7 · Router

De router grijpt in

Het kleine, snelle model begint het cv. De router ziet een documentcall en stopt hem: documenten schrijft het sterke model. De poging van het kleine model wordt weggegooid, niet getoond.

trace
if (engine.small && calls.some(isDocumentCall)) {  usage.void(res);                // not shown, not billed to the user  engine = STRONG;                 // replay the same turn  continue;}

Stap 5 / 7 · Tools

De documenten schrijven

Het sterke model schrijft het cv alleen vanuit de bewijsbank. Elke regel hoort bij een bewijsstuk; wat niet te koppelen is, verdwijnt. Het cv wordt gerenderd en moet op één pagina passen.

trace
build_package({ job, cv_master }) →  claims: 14 · mapped to evidence: 14 · removed: 0  render: CV.pdf (1 page ✓) · CV.docx · letter.pdf (1 page ✓)

Stap 6 / 7 · Tracker

De tracker bijwerken

De sollicitatie gaat naar “klaar” en de tijdlijn krijgt een regel. Naar “verstuurd” zetten vraagt een eigen klik van de werkzoekende: de agent verandert nooit zelf een status.

postgresql
update applications set stage = 'ready' where id = $1 and owner = $2;insert into application_events (application, kind, note)values ($1, 'package_built', 'CV + letter, 1 page each');-- 'applied' only via the owner's confirm button

Stap 7 / 7 · Documents

Bestanden worden geleverd

De werkzoekende krijgt een pdf en een bewerkbaar Word-bestand via kortlevende privélinks. Kosten van het hele verzoek: $0,12, waarvan 92% het cv zelf.

trace
turns: haiku 0.0044 · 0.0027 · 0.0025 (void) · sonnet 0.1103total: $0.120  ·  links expire after 1 hour

04

Code

Twee stukken die in deze agent het zwaarst wegen.

Een cv-regel blijft alleen staan als hij verwijst naar iets wat de persoon echt deed.

career/evidence_guard.jsjavascript
export function keepProvenClaims(draft, evidence) {  const byId = new Map(evidence.map((e) => [e.id, e]));  const kept = [], removed = [];  for (const line of draft.lines) {    const ok = line.evidence?.length &&      line.evidence.every((id) => byId.has(id)) &&      numbersMatch(line.text, line.evidence.map((id) => byId.get(id)));    (ok ? kept : removed).push(line);  }  return { ...draft, lines: kept, removed };   // removed lines are logged, never shown}

Chat draait op het kleine model; elke documentcall wordt herhaald op het sterke model.

career/router.jsjavascript
const isDocumentCall = (c) =>  c.name === 'build_package' || Boolean(c.input?.cv_master); for (let round = 0; round < MAX_ROUNDS; round++) {  const res = await model(engine).send(messages, tools);  usage.add(engine.id, res.usage);  const calls = res.content.filter((b) => b.type === 'tool_use');  if (engine === SMALL && calls.some(isDocumentCall)) {    usage.void(res); engine = STRONG; continue;  }  if (!calls.length) return res;  messages.push(res, await runTools(calls, ctx));}
05

Data en vangrails

Wat hij bewaart

  • applicationsbedrijf, rol, fase (10), matchscoreeigen tracker van de eigenaar
  • application_eventstijdlijn: elke wijziging en wie hem deedvolledige geschiedenis
  • evidencerollen, resultaten, cijfers die de persoon kan bewijzenbewerkt door de eigenaar
  • documentscv- en briefversies per sollicitatieprivé-opslag, ondertekende links
  • text_i18nvertalingen van eigen notitiesper account

Wat hem veilig houdt

  • Bewijs of nietsEen bewering zonder bewijs komt nooit in een document.
  • Mensen verplaatsen de statusDe agent mag “verstuurd” of “afgewezen” voorstellen; alleen de eigenaar bevestigt.
  • Eén bedrijf, één kansDubbele worden gemeld vóór een tweede sollicitatie bij hetzelfde bedrijf.
  • PrivébestandenCv’s staan privé en openen via links die binnen het uur verlopen.
