Career Agent

Mencari lowongan, menulis dokumen, dan melacak setiap lamaran sampai tawaran kerja.

10tahap per lamaran
2model: kecil untuk chat, kuat untuk dokumen
$0.12untuk satu permintaan CV yang disesuaikan
0fakta yang boleh dikarang agent
01

Mengapa dibuat

Pencari kerja mengirim puluhan lamaran, kehilangan jejaknya, dan mengirim CV yang sama ke mana-mana. Career Agent menyimpan satu bank bukti tentang apa yang benar-benar pernah dikerjakan orang itu, menyesuaikan setiap CV dan surat dari situ, dan menjaga tracker yang jujur dari “disimpan” sampai “diterima”.

Dipakai olehPencari kerja di MatchupSkills, dari mahasiswa yang mencari magang sampai profesional yang pindah bidang.
02

Satu permintaan, langkah demi langkah

Klik sebuah langkah, atau tekan putar, untuk mengikuti satu permintaan nyata melewati sistem.

Langkah 1 / 7 · Job seeker

Iklan lowongan masuk

Pencari kerja menempel iklan analis data dan meminta CV yang disesuaikan.

trace
"Here's a Data Analyst ad (Rotterdam, hybrid). Tailor my CV and save it."

Langkah 2 / 7 · State

Memuat keadaan

Agent membaca profil, bank bukti, dan tracker, jadi ia tahu apa yang sudah dikirim dan apa yang bisa dibuktikan orang itu.

trace
career_get_state() → { profile, evidence: 41 items, applications: 37,  duplicates: ["same company, other role (applied 9 days ago)"] }

Langkah 3 / 7 · Tools

Simpan dan nilai lowongan

Lowongan disimpan dan dinilai terhadap bukti: keterampilan wajib yang ada, yang kurang, dan yang berisiko. Di sini kecocokannya 70/100 dan agent menyebut celah mana yang penting.

trace
save_jobs([{ title: "Data Analyst", city: "Rotterdam" }])score_fit → { score: 70, band: "risky",  matched: ["SQL", "Power BI", "stakeholders"],  missing: ["dbt"], note: "say SQL pipelines, not dbt" }

Langkah 4 / 7 · Router

Router turun tangan

Model kecil yang cepat mulai menulis CV. Router melihat ini panggilan dokumen dan menghentikannya: dokumen ditulis oleh model yang lebih kuat. Percobaan model kecil dibuang, tidak ditampilkan.

trace
if (engine.small && calls.some(isDocumentCall)) {  usage.void(res);                // not shown, not billed to the user  engine = STRONG;                 // replay the same turn  continue;}

Langkah 5 / 7 · Tools

Menulis dokumen

Model kuat menulis CV hanya dari bank bukti. Setiap baris dipetakan ke satu bukti; yang tidak bisa dipetakan dihapus. CV dirender dan harus muat satu halaman.

trace
build_package({ job, cv_master }) →  claims: 14 · mapped to evidence: 14 · removed: 0  render: CV.pdf (1 page ✓) · CV.docx · letter.pdf (1 page ✓)

Langkah 6 / 7 · Tracker

Memperbarui tracker

Lamaran pindah ke “siap” dan timeline mendapat catatan. Memindahkannya ke “dikirim” perlu klik pencari kerja sendiri: agent tidak pernah mengubah status sendiri.

postgresql
update applications set stage = 'ready' where id = $1 and owner = $2;insert into application_events (application, kind, note)values ($1, 'package_built', 'CV + letter, 1 page each');-- 'applied' only via the owner's confirm button

Langkah 7 / 7 · Documents

File dikirim

Pencari kerja menerima PDF dan file Word yang bisa diedit lewat link privat berumur pendek. Biaya seluruh permintaan: $0,12, dan 92% di antaranya untuk CV-nya.

trace
turns: haiku 0.0044 · 0.0027 · 0.0025 (void) · sonnet 0.1103total: $0.120  ·  links expire after 1 hour

04

Kode

Dua bagian yang paling menentukan di agent ini.

Baris CV hanya bertahan bila menunjuk sesuatu yang benar-benar pernah dikerjakan orang itu.

career/evidence_guard.jsjavascript
export function keepProvenClaims(draft, evidence) {  const byId = new Map(evidence.map((e) => [e.id, e]));  const kept = [], removed = [];  for (const line of draft.lines) {    const ok = line.evidence?.length &&      line.evidence.every((id) => byId.has(id)) &&      numbersMatch(line.text, line.evidence.map((id) => byId.get(id)));    (ok ? kept : removed).push(line);  }  return { ...draft, lines: kept, removed };   // removed lines are logged, never shown}

Chat berjalan di model kecil; setiap panggilan dokumen diulang di model kuat.

career/router.jsjavascript
const isDocumentCall = (c) =>  c.name === 'build_package' || Boolean(c.input?.cv_master); for (let round = 0; round < MAX_ROUNDS; round++) {  const res = await model(engine).send(messages, tools);  usage.add(engine.id, res.usage);  const calls = res.content.filter((b) => b.type === 'tool_use');  if (engine === SMALL && calls.some(isDocumentCall)) {    usage.void(res); engine = STRONG; continue;  }  if (!calls.length) return res;  messages.push(res, await runTools(calls, ctx));}
05

Data dan pengaman

Yang disimpan

  • applicationsperusahaan, peran, tahap (10), skor kecocokantracker milik pemilik
  • application_eventstimeline: setiap perubahan dan pelakunyariwayat lengkap
  • evidenceperan, hasil, angka yang bisa dibuktikandiedit oleh pemilik
  • documentsversi CV dan surat per lamaranpenyimpanan privat, link bertanda tangan
  • text_i18nterjemahan catatan pemilikper akun

Yang menjaganya aman

  • Bukti atau tidak sama sekaliKlaim tanpa bukti tidak pernah masuk dokumen.
  • Manusia yang memindah statusAgent boleh mengusulkan “dikirim” atau “ditolak”; hanya pemilik yang mengonfirmasi.
  • Satu perusahaan, satu lamaranDuplikat ditandai sebelum lamaran kedua ke perusahaan yang sama.
  • File privatCV disimpan privat dan dibuka lewat link yang kedaluwarsa dalam satu jam.
