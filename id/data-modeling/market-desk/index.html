Market desk

Market desk pribadi yang membaca pasar, mengusulkan setup trading, lalu menilai dirinya sendiri. Ia tidak pernah menjalankan transaksi.

3timeframe dibaca bersama: 1 jam, 4 jam, 1 hari
4analis dibandingkan: satu berbasis aturan, tiga AI
100%setup dinilai dengan harga nyata
0transaksi dijalankan
01

Mengapa dibuat

Opini pasar itu murah; opini yang dilacak itu langka. Desk menulis setiap ide sebagai setup yang tepat (di mana masuk, di mana salah, di mana ambil untung) sebelum hasilnya diketahui, lalu mengecek harga nyata sesudahnya. Lama-lama ia tahu jenis setup mana yang layak dipercaya dan mana yang tidak.

Dipakai olehSaya sendiri. Ini alat riset pribadi di dalam Northstar, aplikasi perencanaan saya.
02

Satu permintaan, langkah demi langkah

Klik sebuah langkah, atau tekan putar, untuk mengikuti satu permintaan nyata melewati sistem.

Langkah 1 / 7 · Scheduler

Paket baru

Pada jadwal tetap, desk menyusun paket: satu potret pasar yang dibaca semua analis.

trace
packet { slot: "2026-11-21T08:00Z", assets: ["BTC","ETH","SOL", …],         macro: { dxy, us10y, fear_greed }, memory: {…} }

Langkah 2 / 7 · Market data

Mengambil harga

Candle untuk tiga timeframe diambil dari data pasar publik, ditambah funding rate untuk kripto. Data yang hilang atau basi menandai aset sebagai “tidak dibaca”, bukan ditebak.

candles("BTC", "1h", 500) · candles("BTC", "4h", 500) · candles("BTC", "1d", 400)if (ageMinutes(last) > 2 * tfMinutes) asset.read = null;   // no stale reads

Langkah 3 / 7 · Indicators

Menghitung indikator

Untuk setiap timeframe: rata-rata 20 dan 50 periode, RSI, MACD, average true range (seberapa jauh harga biasanya bergerak), dan level support serta resistance terdekat.

trace
d: { ema20: 94120, ema50: 89870, rsi14: 61, atr14: 2840, trend_score: 0.6 }h: { rsi14: 55, macd_hist_rising: true, trend_score: 0.4 }h: { trend_score: -0.2 }

Langkah 4 / 7 · Rule engine

Mesin aturan menentukan sikap

Tiga skor tren diberi bobot 50 / 30 / 20 (harian, 4 jam, 1 jam) menjadi satu angka. Hasilnya sikap: long, short, atau tunggu, dan setup dengan zona masuk, stop berdasarkan volatilitas, dan dua target. Tidak ada AI di langkah ini.

trace
composite = 0.5*0.6 + 0.3*0.4 + 0.2*(-0.2) = 0.38  → stance: longsetup { type: "trend_pullback", entry: 93.k–94.k, stop: 91.k,        tp1: 97.k, tp2: 101.k, rr: 1.6 }

Langkah 5 / 7 · AI analysts

Analis AI menambahkan pandangan

Tiga analis AI membaca paket yang sama dan menulis setup mereka sendiri beserta alasannya. Setiap setup divalidasi: stop harus di sisi rugi, target di sisi untung, dan imbal hasil minimal 1,2 kali risikonya. Setup yang tidak valid ditolak, tidak diperbaiki.

trace
cleanSetup(ai) → rejected: "stop above entry for a long"cleanSetup(ai) → ok { type: "breakout", rr: 2.1, confidence: 0.55 }

Langkah 6 / 7 · Grader

Dinilai dengan harga nyata

Kemudian setiap setup diputar ulang terhadap candle yang benar-benar terjadi. Apakah harga mencapai zona masuk? Lalu mana yang lebih dulu: stop atau target? Hasilnya ditulis dalam R, yaitu untung atau rugi dalam satuan risiko yang diambil.

trace
grade(setup, candlesAfter) → { outcome: "tp1", r: +1.6, hours: 31 }grade(setup2, candlesAfter) → { outcome: "stopped", r: -1.0, hours: 9 }

Langkah 7 / 7 · Journal

Ingatan masuk ke paket berikutnya

Win rate dan rata-rata R per jenis setup dan per analis masuk ke paket berikutnya, jadi analis melihat ide mana yang benar-benar berhasil. Jurnal menyimpan setiap call beserta hasilnya.

memory.trend_pullback = { n: 46, win: 0.54, avgR: +0.31 }memory.mean_reversion = { n: 29, win: 0.38, avgR: -0.12, note: "skip against the daily trend" }

04

Kode

Dua bagian yang paling menentukan di agent ini.

Mesin aturan: memberi bobot tiga timeframe menjadi satu skor dan membangun setup dengan stop berbasis volatilitas.

markets/signal.jsjavascript
const WEIGHT = { '1d': 0.5, '4h': 0.3, '1h': 0.2 }; export function composite(tf) {  let s = 0, w = 0;  for (const [k, wt] of Object.entries(WEIGHT))    if (tf[k]?.trend_score != null) { s += tf[k].trend_score * wt; w += wt; }  return w ? s / w : 0;} function setup({ direction, entryLow, entryHigh, stop, targets }) {  const entry = (entryLow + entryHigh) / 2, risk = Math.abs(entry - stop);  if (!risk) return null;  const sign = direction === 'long' ? 1 : -1;  let [tp1, tp2] = targets;  if (tp1 == null || (tp1 - entry) * sign < 1.2 * risk) tp1 = entry + sign * 1.5 * risk;  if (tp2 == null || (tp2 - tp1) * sign <= 0) tp2 = entry + sign * 3 * risk;  return { direction, entryLow, entryHigh, stop, tp1, tp2,           rr: +(Math.abs(tp1 - entry) / risk).toFixed(2) };}

Penilai berjalan maju melewati candle nyata. Bila satu candle menyentuh stop dan target sekaligus, dihitung rugi: asumsi yang jujur.

markets/grade.jsjavascript
export function grade(s, candles) {  const long = s.direction === 'long';  let entered = false;  for (const c of candles) {    if (c.time > s.expires_at) return { outcome: entered ? 'expired' : 'not_triggered', r: 0 };    if (!entered) { entered = c.low <= s.entryHigh && c.high >= s.entryLow; if (!entered) continue; }    const hitStop = long ? c.low <= s.stop : c.high >= s.stop;    const hitTp1  = long ? c.high >= s.tp1 : c.low <= s.tp1;    if (hitStop) return { outcome: 'stopped', r: -1 };          // stop first if both    if (hitTp1)  return { outcome: hitsTp2(s, c) ? 'tp2' : 'tp1', r: rOf(s, hitsTp2(s, c)) };  }  return { outcome: 'open', r: null };}

Data dan pengaman

Yang disimpan

  • packetssatu potret pasar per slotdisimpan untuk diputar ulang
  • reportspandangan tertulis tiap analisdisimpan
  • calls (setups)masuk, stop, target, alasan, sumberhanya menambah, ditulis sebelum hasil
  • gradeshasil dan R per callmasuk ke ingatan

Yang menjaganya aman

  • Hanya analisisTidak ada akun bursa dengan hak trading di mana pun dalam sistem.
  • Tanpa melihat ke belakangCall disimpan sebelum hasilnya diketahui dan tidak bisa diedit.
  • Hanya angka yang masuk akalSetup AI dengan stop di sisi yang salah atau imbal hasil buruk ditolak.
  • Data basi bukan dataBila harga terlambat, aset dilewati, bukan dibaca dari candle lama.
