AI interviewer

Wawancara suara tujuh menit yang bisa diikuti kandidat dari laptop mana pun, kapan saja dalam 24 jam.

24 hlink berlaku, tanpa login
~7 minper wawancara
~$0.17biaya AI per wawancara
0keputusan rekrutmen oleh AI
01

Mengapa dibuat

Menyaring 80 pelamar lewat telepon butuh seminggu panggilan di zona waktu berbeda. AI interviewer memberi setiap kandidat percakapan pertama yang sama dan terstruktur, kapan pun cocok bagi mereka. Tim lalu menonton rekaman dan membaca transkrip sebelum memutuskan.

Dipakai olehKandidat untuk posisi di CAP dan MatchupSkills; tim rekrutmen meninjau di dashboard monitoring.
02

Satu permintaan, langkah demi langkah

Klik sebuah langkah, atau tekan putar, untuk mengikuti satu permintaan nyata melewati sistem.

Langkah 1 / 7 · Link gate

Link dibuka

Kandidat membuka link pribadi. Link berlaku 24 jam, tanpa akun, dan menjelaskan apa saja yang direkam. Tidak ada yang dimulai tanpa persetujuan.

trace
const row = await findByTokenHash(sha256(token));   // the token itself is never storedif (!row || row.expires_at < now()) return expired();if (!row.consent_at) return showConsent(row.position);

Langkah 2 / 7 · Candidate

Cek kamera dan mikrofon

Tes singkat memastikan kedua perangkat berfungsi dan suara cukup keras, sebelum pertanyaan pertama.

trace
level = rms(micFrames) → 0.21  ✓ above 0.05video  = 1280×720 @ fps   ✓

Langkah 3 / 7 · Recorder

Jawaban direkam per potongan

Video diunggah per 10 detik langsung ke penyimpanan privat. Bila browser mogok, paling banyak 10 detik hilang dan kandidat bisa memuat ulang lalu lanjut.

trace
recorder.ondataavailable = (e) =>  putChunk(sessionId, seq++, e.data);   // signed upload URL, private bucket// reload = new session; the last question is asked again

Langkah 4 / 7 · Speech→text

Suara menjadi teks

Saat kandidat berhenti bicara, jawabannya ditranskripsi. Transkrip, bukan audio, yang dibaca model pewawancara.

trace
{ turn: 4, seconds: 52,  text: "In my last project I cleaned 30 thousand rows of survey data…" }

Langkah 5 / 7 · Interviewer

Pewawancara mengajukan pertanyaan berikutnya

Claude mengikuti rencana pertanyaan untuk posisi itu dan mengajukan satu pertanyaan lanjutan dari jawaban terakhir. Deskripsi posisi dan rencana di-cache, jadi setiap giliran hanya sepersekian sen. Rem keras menghentikan yang kebablasan: batas giliran, batas biaya, dan batas waktu.

trace
if (s.turns >= MAX_TURNS || s.usd >= MAX_USD || s.elapsed >= MAX_TIME)  return closeWith('Thank you, that is all for today.');const q = await interviewer.next({ plan, transcript: s.transcript });

Langkah 6 / 7 · Text→speech

Pertanyaan diucapkan

Pertanyaan dibacakan dengan suara alami. Bila layanan suara gagal, suara kedua mengambil alih; bila keduanya gagal, pertanyaan tampil sebagai teks dan wawancara tetap berjalan.

trace
audio = await speak(q, VOICE).catch(() => speak(q, BACKUP_VOICE)).catch(() => null);render({ text: q, audio });     // text always shown as captions

Langkah 7 / 7 · Review

Tim meninjau

Di akhir, potongan digabung menjadi satu video tanpa encode ulang, ringkasan terstruktur ditulis, lalu tim menonton dan membaca. AI tidak pernah meloloskan atau menolak kandidat.

trace
ffmpeg -f concat -i parts.txt -c copy interview.webm   # seekable, no quality losssummary: { strengths: 3, concerns: 2, quotes: 4 }  ·  status: unchanged

04

Kode

Dua bagian yang paling menentukan di agent ini.

Job terjadwal memastikan tidak ada yang tertinggal setengah jalan, dan video tidak disimpan lebih lama dari yang dijanjikan.

interview/sweep.jsjavascript
export async function sweep(db, store) {  // 1. abandoned: no answer for 15 minutes → close and summarise what exists  for (const s of await db.silentSessions({ minutes: 15 })) await finalize(s, { partial: true });   // 2. summaries that failed get up to three more tries  for (const s of await db.failedSummaries({ maxTries: 3 })) await summarise(s);   // 3. retention: video, transcript and scores go after 90 days unless hired  for (const s of await db.olderThan({ days: 90, exceptStatus: 'hired' })) {    await store.removeFolder(s.id);    await db.clearPersonalData(s.id);  }}

Tiga pemicu bisa menyelesaikan wawancara yang sama bersamaan; hanya satu yang menang.

interview/claim.jsjavascript
const { data } = await db.from('interviews')  .update({ status: 'finalizing', claimed_at: new Date() })  .eq('id', id).eq('status', 'in_progress')        // compare-and-swap  .select('id').maybeSingle();if (!data) return;                                   // someone else is on it
05

Data dan pengaman

Yang disimpan

  • interviewsposisi, status, hash token, biaya, waktu90 hari kecuali diterima
  • recordingsatu file video yang bisa di-seek per wawancarapenyimpanan privat, link bertanda tangan
  • transcriptsetiap pertanyaan dan jawaban beserta waktu90 hari kecuali diterima
  • scorecardsnilai dari pewawancara manusiabersama lamaran

Yang menjaganya aman

  • Persetujuan duluTidak ada yang direkam sebelum kandidat menyetujui ketentuan yang jelas.
  • Rem kerasSetiap wawancara punya batas giliran, biaya, dan waktu, jadi loop tidak bisa menghabiskan biaya.
  • Manusia memutuskanAI menulis ringkasan. Hanya tim yang memindahkan kandidat.
  • Hapus tepat waktuVideo dan transkrip dihapus setelah 90 hari, sesuai janji di teks persetujuan.
