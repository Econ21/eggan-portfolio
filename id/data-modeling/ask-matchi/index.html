Ask Matchi

Tutor AI yang menilai, memberi kuis, dan meriset dalam satu chat yang mengingat pelajarnya.

12jalur belajar yang bisa dijalankan
73%token input berasal dari prompt cache
3bahasa antarmuka

01

Mengapa dibuat

Pelajar yang menyiapkan IELTS, beasiswa, atau tes masuk memakai lima alat sekaligus: chatbot, aplikasi kuis, penilai, mesin pencari, dan catatan. Ask Matchi menggabungkan kelimanya dalam satu percakapan. Ia tahu tujuan, level, dan riwayat pelajar, jadi setiap jawaban berangkat dari posisi pelajar, bukan dari nol.

Dipakai olehPelajar di aplikasi MatchupSkills (web dan HP), dalam bahasa Inggris, Indonesia, atau Belanda.
02

Satu permintaan, langkah demi langkah

Klik sebuah langkah, atau tekan putar, untuk mengikuti satu permintaan nyata melewati sistem.

Langkah 1 / 7 · Learner app

Pelajar bertanya

“Nilai esai IELTS Task 2 saya dan buatkan rencana dua minggu.” Esainya dilampirkan sebagai teks.

trace
POST /chat{  "thread": "th_8f2…",  "text": "Grade my IELTS Task 2 essay and give me a two-week plan.",  "attachments": [{ "kind": "essay", "words": 287 }],  "lang": "en"}

Langkah 2 / 7 · Gateway

Gateway: siapa, dan apakah saldonya cukup?

Sesi diverifikasi, lalu paket dan saldo kredit dicek sebelum ada panggilan model berbayar. Pelajar tanpa kredit mendapat pesan yang jelas, bukan jawaban setengah jadi.

trace
const learner = await requireLearner(req);          // signed session onlyconst estimate = estimateTurnCost(body, learner.plan);if (!(await canSpend(learner, estimate)))  return reply(402, t('Top up to continue'));       // before any model call

Langkah 3 / 7 · Context

Konteks: siapa pelajar ini?

Prompt disusun berlapis. Aturan tetap dan rubrik di depan dan di-cache, jadi tidak dibayar ulang setiap giliran. Lalu kartu profil singkat, ringkasan percakapan sebelumnya, dan pesan baru.

trace
system: [  { type: 'text', text: TUTOR_RULES + RUBRICS,          // ~6k tokens, same for all    cache_control: { type: 'ephemeral' } },  { type: 'text', text: profileCard(learner) },        // goal, level, exam date  { type: 'text', text: await memorySummary(learner) } // earlier threads, CV reviews]

Langkah 4 / 7 · Claude

Model merencanakan

Claude membaca permintaan dan memutuskan alat yang dibutuhkan: menilai esai dulu, lalu mengecek tanggal tes resmi di web, lalu menggambar rencana. Token mengalir ke layar selama ia bekerja.

trace
→ tool_use  grade_writing   { exam: "ielts", task: 2 }→ tool_use  web_search      { q: "IELTS test dates The Hague 2027" }→ tool_use  show_chart      { kind: "plan", weeks: 2 }

Langkah 5 / 7 · Tools

Alat mengerjakan tugas sebenarnya

Penilai memberi skor empat kriteria IELTS berdasarkan band descriptor. Hasil web baru sampai ke pelajar setelah halamannya dibuka dan dicek: harus terbuka, tetap di situs yang sama, dan benar-benar memuat klaimnya.

trace
{ "task_response": 6.5, "coherence": 6.0,  "lexical": 6.5, "grammar": 6.0, "overall": 6.5,  "fix_first": ["topic sentences", "linking beyond 'moreover'"] } sources: 2 found · 2 opened · 1 kept (1 redirected → dropped)

Langkah 6 / 7 · Database

Semua dicatat

Hasilnya masuk ke indeks aktivitas belajar, jadi dashboard, riwayat, dan streak ikut berubah tanpa kode tambahan. Setiap panggilan model dicatat beserta biayanya, dan riset ditagih sesuai biaya plus margin tetap.

postgresql
insert into writing_results (learner, exam, overall, detail)values ($1, 'ielts', 6.5, $2);-- trigger → learning_activity (one row per session, any feature) insert into ai_cost_log (feature, model, input_tokens, cached_tokens, usd)values ('matchi', 'sonnet', 7412, 5980, 0.0213);

Langkah 7 / 7 · Stream

Jawaban sampai

Pelajar melihat skor band, dua hal yang harus diperbaiki dulu, grafik rencana dua minggu, dan kartu sumber yang bisa dibuka. Waktu sampai kata pertama: sekitar satu detik.

stream: text · card(score) · chart(plan) · sources[1]first_token_ms: 980   total_ms: 11240   usd: 0.031

04

Kode

Dua bagian yang paling menentukan di agent ini.

Sumber yang dikutip harus lolos empat cek sebelum dilihat pelajar.

matchi/verify_link.jsjavascript
export async function verifyLink(url, claim) {  const u = new URL(url);  if (u.protocol !== 'https:' || isPrivateHost(u.hostname)) return drop('unsafe');   const res = await fetch(u, { redirect: 'manual', signal: timeout(6000) });  if (res.status >= 300 && res.status < 400) {    const to = new URL(res.headers.get('location'), u);    if (to.hostname !== u.hostname) return drop('redirects elsewhere');  }  if (!res.ok) return drop('dead link');   const text = readable(await res.text()).slice(0, _000);  if (!mentions(text, claim.keyTerms)) return drop('does not contain the claim');  return keep({ url: u.href, title: titleOf(text) });}

Riset ditagih sesuai biaya sebenarnya plus margin tetap. Token dari cache lebih murah, jadi pelajar juga membayar lebih sedikit.

matchi/billing.jsjavascript
export function creditsForTurn(usage, rates, margin = 0.5) {  const usd =      usage.input_fresh  * rates.input    + usage.input_cached * rates.cached      // ~10% of the fresh price    + usage.output       * rates.output    + usage.searches     * rates.search;  const charge = usd / (1 - margin);         // keep the margin on every turn  return Math.ceil(charge * CREDITS_PER_USD);}
05

Data dan pengaman

Yang disimpan

  • threads · messagespercakapan, per pelajardisimpan selama akun ada
  • learning_activitysatu baris per sesi di fitur apa pun, diisi triggerriwayat dan streak
  • writing_results · quiz_resultsskor, kriteria, dan umpan balikdisimpan untuk grafik progres
  • saved_opportunitiesbeasiswa dan lowongan yang ditemukan agentsampai pelajar menghapusnya
  • ai_cost_logmodel, token, dan biaya setiap panggilanlaporan keuangan dan margin

Yang menjaganya aman

  • Cek saldo sebelum berpikirKredit dicek sebelum panggilan berbayar dan dikembalikan bila gagal.
  • Tidak ada sumber karanganLink hanya ditampilkan setelah terbuka, tetap di situsnya, dan memuat klaimnya.
  • Satu akun, satu ingatanIngatan, recall, dan terjemahan terikat pada akun, sehingga satu pelajar tidak bisa memengaruhi jawaban pelajar lain.
  • Model mengusulkan, server memutuskanSetiap argumen alat divalidasi di server. Model tidak bisa menyentuh tabel atau file secara langsung.
